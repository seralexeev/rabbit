Forge holds telemetry from the Rabbit robot (drive motors, the 99 Wh 4S battery and power rails, steering, ZED camera IMU, magnetometer, barometer and pose, Jetson computer, Wi-Fi), every command sent to it with its sender, navigation and exploration state, configuration changes and the log records of all its nodes in ClickHouse, one run per recording session, on one clock.

Start with list_runs. For a question, search_slabs and run_slab first: slabs are reviewed queries whose columns carry units and measures (gauge values are averaged or taken as min or max, never summed over time; counter values are differences; event values sum; ratio values are recomputed, never averaged). Write SQL with query only when no slab fits; read describe_schema first. detect_anomalies flags unusual stretches of up to four related signals against a joint forecast that accounts for their covariates. metric_graph shows how metrics relate, and investigate walks it from a symptom to ranked causal chains with evidence, plus the commands, state transitions and logs around the focus. list_metrics catalogs every metric id with its table and NATS subject. timeline returns everything around a moment: commands, transitions, logs and a summary of every metric. search_logs and logs_around read the robot's logs. ask answers a plain-language question end to end.
