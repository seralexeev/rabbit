# 2026-10-11 Blog: per-post pages, SEO and a lightbox

The blog (`workspaces/blog`, https://rabbit0.dev) was one long page per language with weak meta and 640 px, quality-50 thumbnails that opened in a new tab. The generator now builds a proper static site on every deploy.

## Before (live site, 2026-10-11)

- `/` and `/ru` (served from `ru.html`): both had `<html lang="en">`, the same `<link rel="canonical" href="https://rabbit0.dev/">`, the same English title and description, no `hreflang`. Google would treat `/ru` as a duplicate of `/`.
- No `sitemap.xml` (404), no favicon (404), `robots.txt` without a sitemap line, no feed, the GitHub default 404 page.
- `og:image` was the 500 × 270 animated logo GIF; no per-post URL to share, only `/#<id>` anchors.
- Images: `alt="Preview"`, no `width`/`height` (layout shift), one 640 px WebP at `-q 50` per image; the Google Fonts stylesheet sat after `</body>`.

## Now

| Output | What |
|---|---|
| `/`, `/ru/` | index per language: own `lang`, title, description, canonical, `hreflang` en/ru/x-default, `WebSite` + `Blog` JSON-LD |
| `/p/<id>/`, `/ru/p/<id>/` | a page per post (193 × 2): title from the first sentence (≤ 60 chars) + `· Robot Rabbit #<id>`, description from the text (≤ 160), `og:type=article` with the post's first photo as the card, `article:published_time` (midnight Sydney), `BlogPosting` (+ `VideoObject`, `translationOfWork`/`workTranslation`) and `BreadcrumbList` JSON-LD, older/newer links |
| `/feed.xml`, `/ru/feed.xml` | Atom, latest 50 posts, full HTML |
| `/sitemap.xml` | 389 URLs with `xhtml:link` alternates; `robots.txt` points to it |
| `/404.html` | `noindex`; redirects the old `/ru.html` to `/ru/` |
| icons | `favicon.ico`, `icon-192/512.png`, `apple-touch-icon.png`, `site.webmanifest` (pixel bunny from `media/logo.gif`); default card `media/og.jpg` (1200 × 630 crop of `167-1.jpg`) |
| media | previews at 640 and 1280 px WebP `-q 80` in `media/preview/` with `srcset`/`sizes`, `width`/`height`, first image `fetchpriority=high`; click opens PhotoSwipe 5.4.4 (+ video plugin 1.0.2): zoom, swipe, keyboard, videos play inline |

`/ru` → `/ru/` is a GitHub Pages directory redirect (301); old `/#<id>` and `/ru#<id>` anchors still work because the indexes keep `id="<id>"` on every post.

Built output is gitignored (pages, feeds, sitemap, `vendor/`, `media/preview/`); CI (`.github/workflows/blog.yml`) runs on Node 26, type-checks (`npm run typecheck`, TypeScript 7), builds, and caches `media/preview/` keyed by `src/utils.ts` and the media. A full preview build takes ~37 s on the Mac. Dependencies moved to the latest: marked 18.1.0, js-yaml 5.4.3 (ships its own types, `@types/js-yaml` dropped), zod 4.6.5, @types/node 26.6.5, TypeScript 7.0.2; output for the existing posts is unchanged.

Checks run: html-validate (recommended rules minus whitespace/void style/numeric ids) clean on all 391 pages; `xmllint` on the feeds and sitemap; every JSON-LD block parses and every `BlogPosting` has headline, date, author, image, url; no duplicate titles; no horizontal scroll at 375 px; the lightbox opens photos and plays a portrait video (`/ru/p/103/`).

Gray text went from `#aaa` (2.3:1 on white) to `#6b6b6b` and links from `#007aff` to `#0062cc` to pass WCAG AA contrast.

Open: Search Console / Bing verification and `www.rabbit0.dev` (no DNS record) are the owner's (Q51 in `open-issues.md`). Two Russian posts share the same text, so their descriptions repeat; left as written.
