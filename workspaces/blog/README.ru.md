Отсюда в логах «прыжки» на 4 километра и испорченная карта с препятствиями там где робот только что проехал. Еще статус KNOWN_MAP через 5-8 секунд снова сменяется на INITIALIZING, так что «нашел себя» теперь засчитывается только после 10 секунд стабильного статуса.

Фильтр получился простой: если поза прыгнула дальше чем робот мог доехать, она 4 секунды на карантине. Вернулась назад, значит это был глюк. Осталась на новом месте, значит это настоящая коррекция.

```python
def update(self, now, position):
    if self.accepted is None or self.reachable(self.accepted, now, position):
        self.accepted = (now, position)
        self.pending = None
        return True
    if self.pending is not None and self.reachable(self.pending[1:], now, position):
        if now - self.pending[0] >= self.settle_s:
            self.accepted = (now, position)
            return True
        return False
    self.pending = (now, now, position)
    return False
```

Заодно разобрал по телеметрии питание. Понижайка на 12 V для моторов на стартах упирается в свой предел и проседает до 11.3 V, а датчик тока батареи показал 7.6 A при потолке 8.2 A, то есть пики он, скорее всего, просто обрезал. В новой схеме у каждой ветки свой предохранитель, а Pi может выключить и перезапустить зависший Jetson. И будет нормальная кнопка выключения: 93 из 104 загрузок Jetson были после того, как просто выдернули питание.

Средний этаж робота теперь будет не акрилом с кучей модулей и проводов, а платой той же формы. Контур и отверстия под стойки сняли прямо с 3D модели шасси, так что она встает на место акрила без переделок.

На плате Raspberry Pi, RoboClaw, понижайки, предохранители на каждую ветку, INA4235 с шунтами, PCA9685 для руля, часы и все разъемы по краям, каждый смотрит в сторону своего устройства. Снизу пусто, там Jetson и моторы. 4 слоя, батарейная цепь держит ~16 A.

Самое прикольное, что ее никто не рисовал мышкой. Плата описана кодом на Python, KiCad собирает ее из скрипта, сигналы разводит Freerouting, а проверки и файлы для завода делает kicad-cli. Поменял что-то в коде, перезапустил, получил новую плату. 5 штук с монтажом на JLCPCB выходят ~$200-260.

Моторную часть специально собрали в одном углу: хочу перейти на BLDC моторы и потом заменить RoboClaw контроллером прямо на плате, не двигая все остальное.
